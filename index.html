5. My Web Development Process

Steps followed when developing a basic web page from scratch:

  1. Requirement Analysis: Identify the purpose of the website and list the required content sections.
  2. Semantic Wireframing: Map sections to semantic elements (<header>, <nav>, <main>, <section>, <footer>).
  3. Content Markup: Write pure HTML using appropriate headings (h1 through h6), paragraphs, lists, and tables.
  4. Interactive Forms & Inputs: Add form controls with accessible labels, placeholder text, and validation constraints.
  5. Validation & Testing: Check links, inspect image rendering, and test in modern web browsers.
  6. Version Control & Deployment: Commit changes to Git and push to GitHub repositories.

6. Frequently Asked Questions (FAQ)

Click on each question below to toggle the answer (Pure HTML feature):

Why is this project built with ONLY HTML and NO CSS?

Building an HTML-only project reinforces fundamental web architecture. It ensures you fully understand semantic tags, document hierarchy, forms, lists, and accessibility before adding visual styles with CSS.


What are semantic HTML tags and why do we use them?

Semantic tags clearly describe their meaning to both the browser and developer. Tags like <article>, <section>, and <nav> improve search engine optimization (SEO), screen reader accessibility, and code readability.


What is the next step after Day 10?

From Day 11 onwards, styling with CSS (Cascading Style Sheets) will be introduced to transform plain HTML documents into visually appealing, modern, and responsive web layouts.
