1. Basic Form Structure (<form>, <label>, <input>)

Key Concepts:
  • <form> acts as a container for user input controls. Key attributes are action (URL where data is sent) and method (GET or POST).
  • <label for="id"> connects text to an input field. Clicking the label focuses the corresponding input, which improves accessibility and user experience.
  • name specifies the key name when sending form data to a server.

3. Selection Inputs (Radio, Checkbox, Select, Datalist)

Key Difference:
  • Radio buttons: Allow only ONE selection from a group sharing the identical name attribute.
  • Checkboxes: Allow ZERO, ONE, or MULTIPLE independent selections.
  • Select dropdown: Dropdown menu with <option> and optional <optgroup>.
  • Datalist: Input field with autocomplete suggestions via <datalist>.
Provides interactive autocomplete recommendations.

4. Date, Time, Color, Range & Multi-line Text

Modern HTML5 includes native picker widgets for dates, times, colors, ranges, and file attachments without needing third-party libraries.

5. Grouping Form Elements (<fieldset> & <legend>)

Use <fieldset> to logically group related fields together, and <legend> to provide a clear caption for the group. This helps users navigate long forms.
