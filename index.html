HTML Lists Masterclass

Learn how to structure items, steps, definitions, and navigation menus using HTML lists.

<ul> & <li>

1. Unordered List (Bullet Points)

Used when the order of the items does not matter. Each item is wrapped inside an <li> (list item) tag.

<ol> & <li>

2. Ordered List (Numbered Sequences)

Used when item sequence or ranking matters (e.g., steps, recipes, rankings). Supports attributes like type, start, and reversed.

Standard Numbers (Default 1, 2, 3...):

  1. Plan website wireframe
  2. Write semantic HTML markup
  3. Style with modern CSS
  4. Deploy to GitHub

Roman Numerals with type="I" & start="5":

  1. Fifth Major Phase
  2. Sixth Major Phase
  3. Seventh Major Phase

Reversed Countdown with reversed:

  1. Launch website to production
  2. Run end-to-end testing
  3. Review pull request code
<dl>, <dt> & <dd>

3. Description / Definition List

Used for terms and descriptions, metadata pairs, or glossaries. Uses <dl> (description list), <dt> (term), and <dd> (definition/description).

<ul>
Unordered List element used for bulleted lists.
<ol>
Ordered List element used for sequentially numbered lists.
<li>
List Item element placed inside unordered or ordered lists.
<dl>
Description List element used to enclose term-description pairs.
Nested Lists

4. Nested Lists (Multi-Level)

You can nest a list inside an <li> tag of another list to create outlines, table of contents, and hierarchical structures.
