Day 6: HTML Links & Media

A beginner-friendly guide demonstrating hyperlinks (<a>) and media elements (<img>, <audio>, <video>, <iframe>) in HTML.

🔗 Hyperlinks 🖼️ Images 🎵 Audio 🎬 Video 🌐 iFrame Embed

1. HTML Hyperlinks (<a> Tag)

The anchor tag defines hyperlinks used to navigate between web pages, sections, or external sites.

External Link (opens in new tab):

Visit GitHub Repository (DAY-6-OF-FRONTEND)
Uses target="_blank" and rel="noopener noreferrer" for security.

Internal Bookmark Link:

Jump directly to the Video Section ↓
Uses href="#element-id" to jump to any element on the current page.

Email Link (mailto):

Send an Email
Opens default mail client using href="mailto:address".

Telephone Link (tel):

Call Support (+1 234 567 890)
Dials phone number on mobile devices using href="tel:number".

Download Link:

Download Avatar Image
Prompts the user to save file using download attribute.

The <audio> tag plays sound files. The controls attribute provides play/pause and volume controls.
