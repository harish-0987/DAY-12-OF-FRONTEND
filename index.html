🎨 Day 12 Core Focus: The 3 Types of CSS

CSS can be added to HTML in three distinct ways. Each method serves specific use cases, has unique pros and cons, and occupies a different position in the CSS cascade algorithm.

1. Inline CSS

Applied via style=""

Inline CSS is written directly inside the opening tag of an HTML element using the style attribute.

Syntax: <element style="property: value;">

  • Scope: Applies ONLY to this single element.
  • Precedence: Highest specificity (1,0,0,0).
  • Best For: Quick tests, emails, dynamic JS styles.
  • Drawback: Mixes content with design; unmaintainable.
2. Internal CSS

Applied via <style>

Internal (Embedded) CSS is defined within a <style> tag located inside the document's <head> section.

Syntax: <head><style> selector { ... } </style></head>

  • Scope: Applies to the entire current HTML page.
  • Precedence: Standard selector specificity.
  • Best For: Single-page sites, unique landing pages.
  • Drawback: Cannot be shared across multiple HTML files.
3. External CSS

Applied via <link>

External CSS resides in a standalone .css file and is linked to the HTML page using the <link> element.

Syntax: <link rel="stylesheet" href="style.css">

  • Scope: Can style thousands of pages simultaneously.
  • Precedence: Depends on link position & specificity.
  • Best For: Real-world production web development.
  • Benefit: Cached by browsers, clean separation of concerns.

6. Frequently Asked Questions (FAQ)

Why is External CSS preferred over Inline and Internal CSS?

External CSS keeps presentation completely decoupled from HTML structure. It allows one stylesheet to manage the look and feel of thousands of pages, improves loading times through browser caching, and keeps code clean and maintainable.

When is Inline CSS ever acceptable?

Inline CSS is typically used for quick debugging, testing dynamic styles applied via JavaScript, or formatting HTML email templates where external stylesheets are frequently blocked by email clients.

What happens when Inline CSS conflicts with External CSS?

By default, Inline CSS wins because it has a specificity score of 1,0,0,0, which is higher than external element or class selectors. The only way external CSS can override inline styles is by utilizing the !important flag.
